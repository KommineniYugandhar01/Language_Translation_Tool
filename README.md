🌍 Language Translation Tool
# Project Overview
The Language Translation Tool is a Python-based desktop application developed using Tkinter. It enables users to translate text between multiple languages through an intuitive graphical user interface (GUI). The application uses the Google Translate API (googletrans) for translation and includes additional features such as Copy and Text-to-Speech (Speak) for improved usability.

# Features
🌐 Translate text between 100+ languages
🖥️ User-friendly Tkinter GUI
📋 Copy translated text to clipboard
🔊 Text-to-Speech (Speak) functionality
🌍 Select source and target languages
⚠️ Error handling for invalid input
🎨 Simple and attractive interface

# Technologies Used
Python 3.x
Tkinter
Googletrans
gTTS (Google Text-to-Speech)
Playsound
# Installation
Step 1: Clone the Repository
git clone https://github.com/yourusername/Language-Translation-Tool.git
cd Language-Translation-Tool
Step 2: Install Required Libraries
pip install googletrans==4.0.0rc1
pip install gtts
pip install playsound==1.2.2
How to Run

# Run the following command:

python language_translation_tool.py

# Working Procedure
Enter the text to be translated.
Select the source language.
Select the target language.
Click the Translate button.
View the translated text.
Use the Copy button to copy the translated text.
Use the Speak button to hear the translated text.
